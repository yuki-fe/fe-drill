主キーと外部キーの違い

主キーは表の中で1行を1つに決める列（の組）です。外部キーは、ほかの表の主キーを参照する列で、表と表をつなぎます。

表で比べる

観点主キー外部キー
役目表の中の行を1つに特定するほかの表の主キーを参照して、表どうしを関連づける
重複許されない許される（同じ値が何行あってもよい）
空の値（NULL）許されない許されることがある
守られる制約一意性制約・非NULL制約参照制約（参照先にない値は入れられない）
E-R図での表し方下線を引く破線の下線を引くことが多い

見分けるポイント

  • 主キーは「重複なし・空なし」
  • 外部キーは「参照先にある値だけ」（参照制約）
  • 参照されている行を消そうとすると、参照制約に反してエラーになることがある

試験での出され方

表の定義を見て、主キー・外部キーになる列を選ぶ問題や、参照制約に反する操作（参照先にない値の追加、参照されている行の削除）を選ぶ問題がよく出ます。

それぞれの用語

  • 主キー

    表の行を一意に識別する列。値の重複とNULLは許されない。

  • 外部キー

    他の表の主キーを参照する列。参照整合性を保つために使う。
