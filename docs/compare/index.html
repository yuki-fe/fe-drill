似た用語の違い基本情報技術者試験でまぎらわしい用語 15組

試験では、似た用語の違いがよく問われます。2つ（3つ）の用語を表で並べて、どこが違うかを確かめましょう。

  • TCPとUDPの違い

    TCPは届いたかを確かめながら送る「確実さ重視」、UDPは確かめずにどんどん送る「速さ重視」のプロトコルです。どちらもトランスポート層で働きます。

  • 共通鍵暗号方式と公開鍵暗号方式の違い

    共通鍵暗号方式は暗号化と復号に同じ鍵を使い、公開鍵暗号方式は「公開鍵」と「秘密鍵」の対になった2つの鍵を使います。速さと鍵の配り方が大きく違います。

  • DRAMとSRAMの違い

    DRAMはコンデンサに電気をためて記憶するので、定期的に書き直し（リフレッシュ）が必要です。SRAMはフリップフロップ回路で記憶し、リフレッシュがいらず速いぶん高価です。

  • RAID0・RAID1・RAID5の違い

    RAIDは複数のディスクを1台のように使う技術です。RAID0は速さ、RAID1は複製による信頼性、RAID5はパリティを使って速さと信頼性の両方をねらいます。

  • フルバックアップ・差分バックアップ・増分バックアップの違い

    差分バックアップは「最後のフルバックアップから変わった分」、増分バックアップは「前回のバックアップ（フル・増分）から変わった分」を保存します。バックアップの時間と、元に戻す手間が逆になります。

  • ライトスルーとライトバックの違い

    どちらもキャッシュメモリへの書き込み方式です。ライトスルーはキャッシュと主記憶に同時に書き、ライトバックはまずキャッシュだけに書いて、追い出すときに主記憶へ書きます。

  • ウォーターフォールモデルとアジャイルの違い

    ウォーターフォールモデルは要件定義から順に工程を進め、前の工程に戻らないのが原則です。アジャイルは短い期間で作って見せることをくり返し、変化に合わせて進めます。

  • ブラックボックステストとホワイトボックステストの違い

    ブラックボックステストはプログラムの中身を見ずに、入力と出力が仕様どおりかを確かめます。ホワイトボックステストはプログラムの中身（命令や分岐）がすべて正しく通るかを確かめます。

  • スタブとドライバの違い

    どちらもテストのときに、まだできていないモジュールの代わりをする仮のプログラムです。スタブは「呼ばれる側」の代わり、ドライバは「呼ぶ側」の代わりです。

  • スタックとキューの違い

    スタックは最後に入れたものから取り出す（後入れ先出し、LIFO）、キューは最初に入れたものから取り出す（先入れ先出し、FIFO）データ構造です。

  • 主キーと外部キーの違い

    主キーは表の中で1行を1つに決める列（の組）です。外部キーは、ほかの表の主キーを参照する列で、表と表をつなぎます。

  • 請負契約・準委任契約・労働者派遣の違い

    請負契約は「仕事の完成」を約束する契約、準委任契約は「事務（作業）を行うこと」を約束する契約です。労働者派遣は、派遣元の会社の労働者が派遣先の指揮命令を受けて働く形です。

  • コンパイラとインタプリタの違い

    コンパイラはプログラム全体を先に機械語へ翻訳してから実行します。インタプリタはプログラムを1命令ずつ解釈しながら実行します。

  • フォールトトレランス・フェールセーフ・フェールソフト・フールプルーフの違い

    どれも故障や誤りへの備えの考え方です。フォールトトレランスは故障しても動き続けること、フェールセーフは安全な側に止めること、フェールソフトは機能を落としてでも動かすこと、フールプルーフは人の誤った操作を防ぐことです。

  • SaaS・PaaS・IaaSの違い

    どれもクラウドサービスの形です。SaaSはソフトウェアまで、PaaSはアプリケーションを動かす土台（OSやミドルウェア）まで、IaaSはサーバやネットワークなどの基盤だけを提供します。
