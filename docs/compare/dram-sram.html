DRAMとSRAMの違い

DRAMはコンデンサに電気をためて記憶するので、定期的に書き直し（リフレッシュ）が必要です。SRAMはフリップフロップ回路で記憶し、リフレッシュがいらず速いぶん高価です。

表で比べる

観点DRAMSRAM
記憶のしくみコンデンサ（電荷をためる）フリップフロップ回路
リフレッシュ必要不要
速さSRAMより遅い速い
集積度・値段集積度が高く、容量あたり安い集積度が低く、高い
主な用途主記憶（メインメモリ）キャッシュメモリ

見分けるポイント

  • 「リフレッシュ」「コンデンサ」「主記憶」は DRAM
  • 「フリップフロップ」「キャッシュメモリ」は SRAM
  • どちらも電源を切ると内容が消える（揮発性）。消えないのはフラッシュメモリ

試験での出され方

「リフレッシュ動作が必要なメモリはどれか」「キャッシュメモリに使われるのはどれか」のように、特徴から選ばせる問題がよく出ます。D は Dynamic（変化する＝電気が抜けていく）、S は Static（そのまま保つ）と覚えると区別しやすくなります。

それぞれの用語

  • DRAM

    コンデンサに電荷をためて記憶するメモリ。定期的なリフレッシュが必要。主記憶に使う。

  • SRAM

    フリップフロップ回路で記憶するメモリ。高速でリフレッシュ不要。キャッシュメモリに使う。
