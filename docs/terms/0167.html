SQLインジェクション

入力欄に不正なSQL文を入れて、データベースを不正に操作する攻撃。

カードで練習する 書いて答える問題に挑戦

図で見る

SQLインジェクションのしくみ（› を押すか、図をタップすると進みます）

  1. ログインの入力欄に、ふつうは名前を入れる
  2. 攻撃者は「' OR '1'='1」のような文字を入れる
  3. SQL 文の条件がいつも正しくなり、全員のデータが出てしまう
  4. 対策：プレースホルダで、入力を文字として扱う

同じ分野の用語

  • チャレンジレスポンス認証

    サーバが送った乱数とパスワードから計算した値を返して認証する方式。パスワードそのものは送らない。

  • クロスサイトスクリプティング

    Webページに悪意のあるスクリプトを埋め込み、閲覧者のブラウザで実行させる攻撃。

  • シングルサインオン

    一度の認証で、複数のシステムやサービスを利用できるようにする仕組み。

  • CSRF

    ログイン中の利用者に、本人が意図しない処理のリクエストを送らせる攻撃。クロスサイトリクエストフォージェリ。

  • 生体認証

    指紋・静脈・顔・虹彩など、身体的な特徴を使って本人を確認する方法。

  • ディレクトリトラバーサル

    ファイル名の指定に「../」などを含め、公開されていないファイルにアクセスする攻撃。
