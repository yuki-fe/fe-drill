テクノロジ系・ネットワーク

HTTP

WebブラウザとWebサーバの間で、Webページなどのデータをやり取りするプロトコル。

カードで練習する 書いて答える問題に挑戦

同じ分野の用語

  • MACアドレス

    ネットワーク機器ごとに割り当てられた48ビットの識別番号。

  • SMTP

    電子メールを送信・転送するためのプロトコル。

  • ARP

    IPアドレスから、対応するMACアドレスを調べるプロトコル。

  • POP3 / IMAP

    メールサーバから電子メールを受信するためのプロトコル。IMAPはメールをサーバに残したまま管理する。

  • NAT

    プライベートIPアドレスとグローバルIPアドレスを変換する技術。ポート番号も変換するものをNAPTという。

  • NTP

    ネットワーク上のコンピュータの時刻を合わせるためのプロトコル。
