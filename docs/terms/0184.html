DMZ

外部と内部のネットワークの間に設ける区域。公開するWebサーバなどを置く。

カードで練習する 書いて答える問題に挑戦

図で見る

DMZ の置き場所（› を押すか、図をタップすると進みます）

  1. インターネットと社内の間に、ファイアウォールを置く
  2. 公開する Web サーバは、間の区域（DMZ）に置く
  3. 外から DMZ の Web サーバには入れる
  4. 外から社内のネットワークには入れない

同じ分野の用語

  • ファイアウォール

    外部ネットワークと内部ネットワークの間で、通信を許可・遮断する仕組み。

  • WAF

    Webアプリケーションへの通信を検査し、SQLインジェクションなどの攻撃を防ぐ仕組み。

  • ボット

    感染したコンピュータを、外部の指令サーバからの命令で遠隔操作できるようにするマルウェア。

  • IDS

    ネットワークやサーバへの不正な侵入を検知し、管理者に知らせる仕組み。

  • ワーム

    自分自身を複製し、ネットワークを通じて他のコンピュータへ感染を広げるマルウェア。

  • IPS

    不正な侵入を検知するだけでなく、その通信を自動的に遮断する仕組み。
