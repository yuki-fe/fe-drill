FE用語ドリルについて基本情報技術者試験の用語を無料で覚える単語帳

FE用語ドリルは、基本情報技術者試験（FE）を受ける人のための無料の学習サイトです。科目Aの知識は345語の単語帳と解説ページで固め、科目Bの擬似言語はプログラムを1行ずつ動かして読めるようにします。

問われる力知識技能（読んで考える力）
試験時間90分100分
問題数60問（四肢択一）20問（多肢選択式）
内容テクノロジ系・マネジメント系・ストラテジ系アルゴリズムとプログラミング16問、情報セキュリティ4問
基準点600点／1,000点満点600点／1,000点満点

合格には、科目Aと科目Bの両方で基準点以上が必要です。片方だけ高得点でも合格にはなりません。（試験要綱 Ver.5.6、2026年10月の試験から適用）

基本情報技術者試験のおすすめの勉強順

  1. 科目Aのテクノロジ系から始める。2の補数・論理積（AND）・配列・レジスタのように、科目Bの土台にもなる用語を先に覚えます。
  2. 擬似言語の書き方に慣れる。記法クイズで、代入・条件分岐・繰り返し・配列の読み方を確認します。
  3. 科目Bのトレースを練習する。トレース練習（20問）とアルゴリズム図鑑で、変数の変化を追います。
  4. マネジメント系・ストラテジ系を足す。範囲を一周したら、間違えた用語だけを復習して穴を埋めます。

科目Bのトレースとは

トレースは、プログラムを上から順に追い、変数の値がどう変わるかを確かめる読み方です。たとえば、配列 {3, 5, 2} の合計を求める次のプログラムを見てみます。

○整数型: total(整数型の配列: data)
  整数型: s ← 0
  整数型: i
  for (i を 1 から dataの要素数 まで 1 ずつ増やす)
    s ← s + data[i]
  endfor
  return s
繰り返しidata[i]s（足したあと）

よくある質問

科目Aと科目Bは、どちらから勉強すればいいですか？

科目Aのテクノロジ系から始めるのがおすすめです。2進数や配列などの用語がわかると、科目Bのプログラムも読みやすくなります。慣れてきたら、トレース練習を並行して進めます。

科目Bの擬似言語とは何ですか？

特定のプログラミング言語ではなく、基本情報技術者試験でプログラムを表すために使う書き方です。記法クイズで読み方を確認できます。

片方の科目だけ基準点を超えれば合格できますか？

できません。科目Aと科目Bの両方で、1,000点満点中600点以上が必要です。

2027年度から試験は変わりますか？

2027年度から新しい試験制度の開始が予定されていて、基本情報技術者試験のシラバス案も公開されています。このサイトの用語は今の出題範囲に合わせていて、新しいシラバスが決まったら見直します。

料金や会員登録は必要ですか？

どちらも要りません。スマホでもパソコンでも使えて、進み具合は使っているブラウザに保存されます。ホーム画面に追加すると、アプリのように開けます。

間違いを見つけたら

用語の説明は、運営者が AI の支援を受けて作り、確かめたうえで載せています。説明の誤りや、足りない用語に気づいたら、お問い合わせフォームから教えてください。
