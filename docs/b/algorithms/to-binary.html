アルゴリズム図鑑

10進数を2進数に変換する

10進数を 2 で割った余りを記録しながら、商が 0 になるまで割り続けます。余りを下の桁から順に並べたものが2進数です。

考え方

  • n mod 2 で一番下の桁（0 か 1）が求まる
  • n ← n ÷ 2 で、その桁を取り除く
  • 配列には下の桁から順に入るので、読むときは逆順にする

計算量

O(log n)

試験でのポイント

  • 13 を変換すると {1, 0, 1, 1} となり、逆から読んで 1101
  • 16進数なら 2 の代わりに 16 で割る

この図鑑の問題を解く

  • トレース練習: 2進数の1の数を数える
