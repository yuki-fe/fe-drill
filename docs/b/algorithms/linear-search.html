アルゴリズム図鑑

線形探索

配列の先頭から順に1つずつ比べて、探している値を見つける方法です。見つかったら、その位置（番号）を返します。

考え方

  • 先頭から順に比べるだけなので、データが整列していなくても使える
  • 見つからなかったときは、配列にない番号（ここでは -1）を返して知らせる
  • 最悪の場合は全部の要素と比べるので、計算量は O(n)

計算量

O(n)

試験でのポイント

  • 見つかった時点で return するので、残りの要素とは比べない
  • 「見つからなかったときに何を返すか」が空欄で問われやすい

この図鑑の問題を解く
