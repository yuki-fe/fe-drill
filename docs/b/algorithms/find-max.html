アルゴリズム図鑑

最大値を求める

配列の先頭の値を仮の最大値にして、残りの要素と順に比べながら、より大きい値が見つかるたびに入れ替えていきます。

考え方

  • 最初に max ← data[1] として、比べる相手を2番目からにする
  • より大きい値が出てきたときだけ max を更新する
  • 全部の要素を1回ずつ見るので、計算量は O(n)

計算量

O(n)

試験でのポイント

  • max の初期値を 0 にすると、負の数だけの配列で正しく動かない
  • 最小値を求める場合は、比較の向き（>）を逆にする

この図鑑の問題を解く

  • 穴埋め問題: 最大値を更新する条件
